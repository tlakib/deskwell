# DeskWell user guide

## Getting around

- **Tray / menu bar icon.** Click: quick panel (next reminder, Done/Snooze/Skip when one is due, water buttons, pause,
  focus 25, test voice, dashboard). Right-click for the menu: Open DeskWell, Pause, Resume,
  Focus Mode, Play Test Voice, Settings, Exit.
- **Closing the dashboard** hides it; DeskWell keeps running. **Exit** in the tray menu quits.
- **Chrome:** click the DeskWell toolbar icon for the same quick panel. The dashboard opens in a tab.

## Reminders

Dashboard → **Reminders**. Each reminder has a schedule (every N minutes, fixed times, dates, once), days, an optional
own time window (or "only during work hours"), start/end dates, delivery (popup + voice, popup, voice, silent
notification, disabled), language, voice, messages, snooze options and behaviour (important, quiet hours, focus,
grouping). Toggle, duplicate or delete from the list.

When a reminder is due: **Done** logs it, **Snooze** brings it back after the chosen minutes, **Skip** dismisses this one,
**Not today** silences it until tomorrow. If you ignore the popup it hides after the time set in Settings.

## Schedule

Dashboard → **Schedule**: work profiles (Office, Study, Personal, Night shift; days, hours, breaks), quiet hours, and a
preview of the next 24 hours. Times always follow your computer's clock and timezone. If you travel, DeskWell shows a
short notice and keeps your local schedule ("09:00" stays 09:00 local time).

## Voice

Dashboard → **Voice Studio**:
- **Bundled voices** Akib (male) and Rimjhim (female), Bangla and English, offline. Preview any reminder type.
- **System voices**: the voices installed on your computer read the message text; set language, voice, rate, pitch.
- **My audio**: upload MP3/WAV/OGG/M4A/WebM (max 15 MB), preview, rename, delete; select it in a reminder.
- **Message library**: add, edit, reorder and delete the messages reminders pick from.

## Focus, water, history

- **Focus & Breaks**: focus mode skips normal reminders and holds important ones until the end; meeting mode can hold all.
- **Water Tracker**: quick buttons, custom amount, undo, daily goal, units, weekly chart.
- **History & Analytics**: per-day counts, completion ratio (done ÷ delivered), CSV export, clear history.

## Backup

Dashboard → **Backup & Sync**: download a backup (optionally with history and audio), restore with a preview (a safety
copy of your current data is saved first), and on desktop optional daily automatic backups. Cloud sync isn't available
in this version.

## Privacy

All data stays on your device: an SQLite database in the app data folder (desktop) or Chrome's extension storage.
DeskWell doesn't collect analytics and never reads keystrokes, screens, clipboard or browsing history. Idle detection in
Chrome uses Chrome's own idle state only.

Health note: DeskWell is a wellness and habit tool, not medical advice.
